# Contributing to Swara

Thank you for your interest in contributing to **Swara**!

## How to Contribute
1. Fork the repository under your GitHub account.
2. Create a feature or fix branch (`git checkout -b feat/my-change`).
3. Keep changes focused and verify builds/tests before committing:
   - Android: `cd apps/android-native && ./gradlew testDebugUnitTest assembleDebug`
   - Workspace: `pnpm test`
4. Open a Pull Request describing what changed and how you tested it.
