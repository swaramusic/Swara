# Swara

Native Android (Kotlin + Jetpack Compose + Media3) and Desktop music player.

## Apps
- `apps/android-native` — Pure Kotlin, Jetpack Compose, Material Design 3, ExoPlayer/Media3.
- `apps/desktop` & `apps/web` — Tauri desktop app and web UI.

## Build Android
```bash
cd apps/android-native
./gradlew testDebugUnitTest assembleDebug
```
